# Kugel

Kugel turns the things you photograph into snow globes you keep on a shelf, shake, and send to a friend.

## Get help

Ask a question or share an idea in [Discussions](https://github.com/AlexW00/kugel/discussions).

For anything private, write to [kugel@weichart.de](mailto:kugel@weichart.de). Tell us which iPhone and iOS version you use, and what happened.
